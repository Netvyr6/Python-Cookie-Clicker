## Features

- Loading screen
- Settings menu
- Level progression system
- Upgrade system
- Clickable cookie interface
- JSON-based save system
- Background music and sound effects
- High-score tracking

## Technologies

- **Python** — Core game logic
- **Tkinter** — Graphical user interface
- **Pygame** — Audio playback
- **JSON** — Saving and loading game data
- **random**, **math**, **time** — Standard Python modules

## Installation

**Requirements:** Python and Pygame.

Install Pygame:

```bash
pip install pygame
```

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

Run the game:

```bash
python main.py
```

Replace `main.py` with the name of the main Python script if necessary.

## About

This project was an opportunity to develop my Python skills by building a complete game with a graphical interface, progression mechanics, audio, and persistent data storage.
